# Fixture provenance

Required by the specification's fixture-provenance rule
(docs/SPECIFICATION.md in open-science-pillars/marketplace): every file in
fixtures/ is recorded here with its source, version, and license or
public-domain status. Synthetic fixtures are generated by a committed
make_fixtures.py so they are reproducible; real-data fixtures are fetched
by script with local caching and never committed above ~5 MB (no Git LFS).

Everything in this directory is read by the golden notebooks and by
nothing else: a fixture builder or a frozen input lives here, a helper a
skill runs at runtime lives in that skill's `scripts/`, and the placement
gate (`osp.py placement-check`) fails a skill that names a file here (the
placement rule, ADR C).
